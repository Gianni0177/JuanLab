# JuanLab - GitHub Pages

Questo repository contiene una pagina statica pronta per GitHub Pages.

## Avvio locale

Puoi aprire direttamente `index.html` nel browser.

## Pubblicazione su GitHub Pages

1. Crea un nuovo repository su GitHub (esempio: `JuanLab`).
2. Esegui push di questi file sul branch `main`.
3. Vai in GitHub: Settings > Pages.
4. In "Build and deployment", seleziona:
   - Source: Deploy from a branch
   - Branch: `main` e cartella `/ (root)`
5. Salva e attendi 1-2 minuti.
6. Il sito sara disponibile all'indirizzo:
   - `https://<tuo-username>.github.io/JuanLab/`

## Personalizzazione rapida

- Modifica i testi in `index.html`
- Cambia palette e font in `style.css`
